HTML Email Signatures

Besnik Qunaku · Software Developer

Hand-coded, table-based email signatures. No generator, no framework, no web fonts, no @font-face. Written against the constraints of the clients they have to survive — principally Outlook Classic, which renders through Microsoft Word rather than a browser engine.

What I have done instead is write the markup against the Word engine's documented constraints from the outset — the table below is the specific list I coded against. Given a Windows machine or a Litmus/Email on Acid account, I can verify and correct any remaining issues quickly, because I know where they come from.

Gmail also clips messages over roughly 102 KB. The largest signature here is under 7 KB, so nothing is at risk of truncation.

Installing

The copy buttons above copy the rendered signature, not its source — which is what every signature editor expects.

Gmail

  1. Click Copy signature on the variant you want.
  2. Settings → See all settings → General → Signature → Create new.
  3. Paste with Cmd/Ctrl+V. Not “paste as plain text”.
  4. Tick “Insert this signature before quoted text… and remove the ‘--’ line”.
  5. Set both Signature defaults dropdowns, then Save Changes.

Outlook New / Web

  1. Settings → Mail → Compose and reply.
  2. Paste, tick both new-message and reply options, Save.

Outlook Classic

  1. File → Options → Mail → Signatures… → New.
  2. Paste, assign to new messages and replies, OK.
