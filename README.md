# Email Signatures — Besnik Qunaku

Hand-coded, table-based HTML email signatures. No generator, no framework, no
web fonts, no `@font-face`.

**Live:** https://besnikqunaku.github.io/email-signature/

## Sets

**Personal** — no logo, so identity is carried by a typographic monogram set in
Georgia, rendered as live text in a coloured table cell rather than an image.

| File | Style |
|---|---|
| `signature-a-monogram-tile.html` | Charcoal tile, gold accent |
| `signature-b-minimal.html` | Single-column, terracotta accent |
| `signature-c-card.html` | Bordered card, teal left bar |

**Kestrel Aviation** — a fictional company, used as a design sample. The top
band reads like a flight strip: registration, base and offset set in Courier
New, where monospace aligns the data rather than decorating it.

| File | Style |
|---|---|
| `kestrel-flight-strip.html` | Ink band, amber rule, monospace contact block |
| `kestrel-compact.html` | No background fills — stays quiet in a reply chain |

## Layout

```
src/<set>/          sources, with __ASSET:<file>__ tokens
assets/             linkedin.png, kestrel.png — generated, not drawn
tools/              PNG generators (zlib, no image library)
page.template.html
build.py            resolves assets, generates the page
dist/               copy-paste ready signatures
index.html          generated — the GitHub Pages landing page
```

## Build

```bash
python3 build.py
open index.html
```

## Techniques

- Nested tables only, `role="presentation"`, `cellpadding/cellspacing/border=0`,
  `border-collapse:collapse`
- `mso-line-height-rule:exactly` on every text cell; `mso-table-lspace/rspace:0pt`
  on every table
- Rules and accent bars are `bgcolor` table cells, not CSS borders
- Monograms and wordmarks are live text, so they survive images-off
- Links double-wrapped in `<a style>` + inner `<span style>` so Outlook and Gmail
  cannot force blue underline
- `mailto:`, `tel:` in E.164, Google Maps links on addresses
- Widths as HTML attributes *and* CSS, integers only
- Largest signature is 5 KB, well clear of Gmail's ~102 KB clipping

## Images

`assets/*.png` are generated by the scripts in `tools/` — each writes the PNG
directly with `zlib`, drawing the shapes as geometry and rasterising them with
4× supersampling. No image library, no design tool. 96px source, 800–1200 bytes,
displayed at 16–26px.

Signatures reference them by absolute `https` URL. `data:` URIs are not an
option: the Gmail signature editor strips them, and Outlook Classic cannot
render them at all.
